# Research

The four Version 1.0 reports are generated by `backend/app/services/research.py`
from stored outputs (`model_versions`, `analysis_outputs`):

1. Can Machine Learning Beat Elo in Professional League of Legends?
2. Competitive Balance in Professional League of Legends
3. Historical Team Performance and Rating Persistence
4. The Concentration of Tournament Success

Fixed text (question, motivation, method, limitations, references) lives in that
file. Findings are produced from the numbers by explicit rules (for example a
difference is called "better" only when its 95% bootstrap interval excludes zero).
Until the analysis has been run on real data, each report is labelled "proposed".

Use `research/reports/` for notebooks or exports you write on top of the platform.
