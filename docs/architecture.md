# Architecture

```
 Oracle's Elixir CSV (manual download)
            │
            ▼
 pipelines/oracle_elixir  ── acquire → inspect → clean → validate → transform → load
            │                         (data/raw → intermediate → processed, reports)
            ▼
 PostgreSQL ◄──── machine_learning/training (Elo grid, features, logistic, evaluation, persist)
            ◄──── analytics/run_all       (balance, concentration, persistence, regional)
            │
            ▼
 FastAPI backend (backend/app)  ── /api/v1/*  (read-only + POST /predictions)
            │                        provider adapters (pending): Riot, GRID, PandaScore
            ▼
 Next.js frontend (frontend/)   ── 8 sections, client-side data fetching via React Query
```

## Decisions

| Decision | Reason |
|---|---|
| Unit = single game | The source is game-level. Series reconstruction needs assumptions about game independence and is a later research extension. |
| Tournament = league + year + split | The source has no tournament name field. |
| Full rebuild on load | Simple and idempotent; the LoL archive fits comfortably in one transaction. Live providers would need incremental upserts instead. |
| Game-specific extension tables (`lol_*`) | Core tables stay game-agnostic; VALORANT/CS2 metrics get their own tables. |
| Research findings generated by rules | Prevents hand-written claims that the numbers do not support. |
| No world map | The source has no country fields; mapping leagues to countries would be a guess. |
| Fonts self-hosted (@fontsource) | No runtime call to Google Fonts; builds offline. |
| Client-side fetching | The frontend can be deployed on Vercel independently of the API and shows explicit loading/error/empty states. |
| In-process TTL cache and rate limit | Enough for one API instance. Use Redis for both when running several instances. |

## Backend layout

```
backend/app/
  core/config.py        settings from environment (.env)
  database/             engine/session, reference-data seed
  models/               SQLAlchemy models (core + lol)
  schemas/              Pydantic response envelope and types
  services/             queries: entities, overview/analytics, predictions, research, explorer
  providers/            adapter interface + Riot / GRID / PandaScore
  api/routes/v1.py      endpoints
  main.py               app, CORS, gzip, rate limit, error handler
```

## Frontend layout

```
frontend/
  app/                  routes (page.tsx = metadata wrapper, view.tsx = client view)
  components/layout     sidebar, mobile drawer, search, game selector, data status, footer
  components/ui         design-system primitives, tables, pickers, states
  components/charts     chart wrappers sharing one theme
  hooks/use-api.ts      React Query wrapper
  lib/                  API client and types, formatting, chart theme
```

Design tokens live in `tailwind.config.ts` and `app/globals.css`; chart colours
in `lib/chart-theme.ts`.
